Technical Overview

Our system understands context, synonyms, and intent using NLP techniques to provide accurate similarity analysis. Unlike basic keyword search, we ensure academic integrity by evaluating semantic depth against the entire repository.

Systematic Analysis Workflow

Processing academic titles through six distinct validation stages.

01

User Input

System captures the proposed academic project title from the secure web interface.

02

Text Preprocessing

Titles are normalized by removing noise, converting to lowercase, and handling special characters.

03

Data Retrieval

Efficiently fetching existing records from the MySQL database for historical comparison.

04

Feature Extraction

SentenceTransformer converts titles into numerical vector features for mathematical analysis.

05

Similarity Calculation

Cosine Similarity calculates the semantic distance between the current input and the dataset.

06

Final Decision

Decision logic categorizes the result based on predefined threshold rules.
