Data Collection

When you use the Project Title Checker System, we collect the project titles you enter into the evaluation field. This is the only information required to perform the core function of the system.

The project titles submitted are used exclusively for similarity checking against our academic repository. Our Machine Learning models process these titles temporarily to compute similarity vectors and return a validation score.
